# Python Quest

RPG fantasy en vue de dessus pour apprendre Python (HTML/CSS/JS vanilla, aucun build).

## Déploiement GitHub Pages
1. Ouvrir le dépôt > Settings > Pages.
2. Source : « Deploy from a branch », branche `main`, dossier `/ (root)`.
3. Enregistrer et attendre environ 2 minutes.
4. Ouvrir `https://rokai-jibe.github.io/Python-Quest_Claude/`.
5. Après une mise à jour, recharger en vidant le cache.

## Avancement (session par session)
- Session 1 : socle (page, erreurs à l'écran, i18n, sauvegarde, déplacement clavier/tactile, village minimal, dialogues).
- À venir : maisons, forêt, combats, Pyodide, donjons, quêtes, validateur.
